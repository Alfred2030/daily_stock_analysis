# A股+美股每日选股神器 — 改造设计（2026-07-29）

## 背景

- 基础：fork 自 [ZhuLinsen/daily_stock_analysis](https://github.com/ZhuLinsen/daily_stock_analysis)（5.9k stars），本 fork 为 [Alfred2030/daily_stock_analysis](https://github.com/Alfred2030/daily_stock_analysis)。
- 原项目能力：对**用户手工配置的自选股**做每日 LLM 分析（多源行情 + 技术指标 + 新闻舆情 + 基本面 → 决策仪表盘 → 推送）。
- 改造目标：从「分析自选股」升级为「**每天自动从 A股 + 美股全市场发现值得买的新面孔**」，并引入 IMDS 财务管理方法论做专业财务分析。

## 已确认决策

| 决策项 | 结论 |
|---|---|
| 「新股」含义 | 全市场筛出的**新面孔**（非 IPO 新股）：近 14 天未推荐过的新候选 |
| 市场范围 | **A股 + 美股** 双市场 |
| 改造路线 | **路线 A：增量挂载** — 新增独立模块，原流水线不动，保留 `git merge upstream/main` 能力 |
| 部署 | 腾讯云香港 Lighthouse（43.160.214.195），**新 PM2 进程，端口 3024**，不碰现有服务 |
| 域名 | `stock.cxodex.com`（用户在域名控制台加 A 记录 → 43.160.214.195，服务器上 nginx + certbot） |
| 推送 | 企业微信群机器人 webhook |
| LLM | GLM5.2（智谱 OpenAI 兼容接口，用户已有 Key，部署时填入服务器 `.env`，不经聊天传递） |

## 架构总览

```
每个交易日两个场次（北京时间，服务器 cron）：
  A股场次 17:30（A股交易日）      美股场次 07:30（美股交易日次晨）

┌─ 第1级 量化初筛（新增 screener/ 模块）─────────────────┐
│  全市场快照（A股: AkShare 东财 ~5400只；美股: 东财美股快照）│
│  → 硬条件过滤（剔除 ST/退市风险/上市<60天/流动性差/仙股）  │
│  → 量化打分（财务质量+技术形态+资金面）→ Top 20           │
│  → 新面孔去重（近14天推荐过的不再出现）                    │
└─────────────────────────────────────────────┘
        ↓ Top 20 写入动态 STOCK_LIST
┌─ 第2级 深度分析（复用原流水线 + 新增模块）─────────────┐
│  原有: 行情/K线/技术指标/新闻舆情 → LLM 决策报告          │
│  新增: IMDS 财务分析模块（imds_finance/）                │
│  新增: 行业情报模块（industry_intel/）                   │
│  强化: 买点分析提示词（支撑压力位/买入区间/触发条件/仓位） │
└─────────────────────────────────────────────┘
        ↓
  企业微信推送（Top 5 精选卡片）+ Web 工作台完整报告（stock.cxodex.com）
```

## 模块设计

### 1. 选股引擎 `screener/`（新增包）

市场无关的两级漏斗，A股/美股各一份配置。

**数据获取（每场次 1-3 个批量接口调用）**
- A股：`ak.stock_zh_a_spot_em()` 全市场快照（价格/涨跌/量比/换手/PE/PB/总市值/流通市值）+ `ak.stock_individual_fund_flow_rank()` 资金流排名
- 美股：`ak.stock_us_spot_em()` 东财美股快照；资金面用成交额与量比代理

**硬条件过滤（可配置 YAML）**
- A股：剔除 ST/*ST/退市整理；上市 < 60 天；日成交额 < 1亿；股价 < 2元；PE < 0 且无成长逻辑的亏损股（保留科创板研发型白名单逻辑从简：首版直接剔除亏损股）
- 美股：剔除 OTC/粉单；日成交额 < $5000万；股价 < $2；非普通股（ETF/权证）

**量化打分（0-100，三维加权，权重可配置）**
- 财务质量 40%：ROE、毛利率、营收/利润同比增速（快照自带或轻量补拉）
- 技术形态 30%：站上 20/60 日线、近 5 日量价配合、距 52 周高点位置
- 资金面 30%：量比、换手率适中区间、主力净流入（A股）/ 相对成交额放大（美股）

**新面孔去重**：SQLite 表 `recommend_history(market, code, date)`，近 14 天出现过的从 Top 20 中剔除并顺位递补。

**输出**：`Top20 候选列表` → 覆写当次运行的 STOCK_LIST，进入原流水线。

### 2. IMDS 财务分析模块 `imds_finance/`（新增包）

移植 `D:\Projects\Cxodex\cxodex-finance-app` 的方法论（peer.js 同行对比口径 + mgmt 管理层指标 + bp 风险计算），市场无关接口，两个数据适配器。

**数据**：A股用 AkShare 财务指标/三大报表（近 8 季度）；美股用 yfinance `financials/balance_sheet/cashflow`（近 8 季度）。

**三张分析卡**
1. **同行对比卡**（peer.js 口径）：毛利率 / 净利率 / ROE / 资产负债率（百分数）+ 存货 / 总资产 / 应收周转率（倍数），vs 同行业中位数（A股行业取东财行业分类；美股取 GICS sector）→ 每项标注 优于/接近/落后 同行
2. **管理层视角卡**（mgmt 口径）：经营现金流 / 净利润比（现金流质量）、四费率（销售/管理/财务/研发）趋势、营收与利润增速的匹配度
3. **风险扫描卡**（bp/Risk 口径）：流动比率、速动比率、有息负债率、应收账款增速 vs 营收增速（异常预警）、存货增速异常、商誉/净资产占比（A股）

**输出**：财务健康评分（0-100，三卡加权）+ 结构化 JSON 喂给 GLM 生成「管理层分析和关注」段落。评分进入推送卡片。

### 3. 行业情报模块 `industry_intel/`（新增包）

- 对当场次 Top 20 涉及的行业去重（通常 5-10 个行业），每行业执行 1-2 次搜索（复用原项目 `search_service`，需配置至少一个搜索源）
- A股场次关键词域：行业政策 / 部委发文 / 产业数据 / 国际贸易摩擦
- 美股场次关键词域：联储与利率 / CPI 与就业 / 关税与出口管制 / 行业监管与大选政策
- GLM 汇总生成「情报 → 影响预测」：每行业一段（利好/利空/中性 + 影响时间窗 + 涉及的候选股）
- 结果注入每只候选股的深度分析上下文 + 独立成推送的「行业情报」章节

### 4. 买点分析强化（改提示词，不改代码结构）

在原有决策报告提示词上叠加输出契约：
- 支撑位 / 压力位（基于近 60 日 K 线）
- 建议买入区间（价格带）
- 触发条件（如「回踩 20 日线缩量企稳再介入」）
- 仓位建议（轻仓试探 / 标准 / 观望）
- 每份报告固定尾注：**「本报告由 AI 生成，仅供研究参考，不构成投资建议」**

### 5. 推送与 Web

- **企业微信**（每场次一条）：标题（市场 + 日期）→ Top 5 精选卡片（代码 / 名称 / 入选理由一句话 / 财务分 / 买点区间 / 主要风险）→ 行业情报三条要点 → Web 链接
- **Web 工作台**：原项目 `webui.py` 原样部署在 3024，nginx 反代 `stock.cxodex.com` + certbot HTTPS；可查完整 20 只报告、历史记录、手动触发

### 6. 部署与运维

- 服务器：`/opt/stock-analysis/`（或家族惯例目录），Python venv + `pm2 start webui --name stock:3024`
- cron（服务器时区注意换算）：A股场次工作日 17:30 CST；美股场次周二至周六 07:30 CST；两场次各自做交易日历检查（原项目已有 A/US 节假日判断）
- `.env` 保存 GLM Key、企业微信 webhook、搜索源 Key —— 用户 SSH 自行填入，不经聊天传输
- 运行完成后账本回写：`30-业务\CXODEX-运维账本\` 新增 `stock-analysis` 条目

## 错误处理

- 快照接口失败：重试 3 次 → 仍失败则跳过该场次并推送「今日数据源故障」告警到企业微信
- 单只股票深度分析失败：跳过该股，不影响其余候选（原项目已有此语义）
- 财务数据缺失（美股新股/财报缺季度）：财务卡显示「数据不足」，健康评分标 N/A，不臆造
- GLM 限流：批内串行 + 指数退避（原项目 LLM 层已有重试）

## 测试

- 端到端冒烟：`--market a --dry-run` 只跑初筛不调 LLM；`--limit 3` 小样本全流程
- 部署后连续观察 3 个交易日推送

## 明确不做（YAGNI）

- 不做自动交易 / 券商接口对接（分析工具，人工决策）
- 不做港股/日韩台（原项目支持，但本期只开 A+US 两场次）
- 不做美股盘中实时监控；每天收盘后各一场
- 不改原项目已有的自选股功能（并存，互不影响）

## 风险与前置条件

1. 用户需加 DNS：`stock.cxodex.com` A 记录 → 43.160.214.195
2. 用户需提供（填服务器 .env）：智谱 GLM Key、企业微信机器人 webhook、至少一个搜索源 Key（Tavily 免费档即可）
3. 东财免费接口有限流风险：初筛快照是单次批量调用，风险低；美股快照条数大（~1万），需分页与缓存
4. GitHub Actions 单次时长限制不适用（本方案跑在自有服务器）
